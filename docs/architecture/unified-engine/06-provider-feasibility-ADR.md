# ADR-001 — Image Generation & Asset Search Feasibility (Sprint A; no provider integrated)
Status: accepted for planning. Decision: NO production provider until Stage 3 gates pass. Sprint B uses mocked providers only.

## Options evaluated (Oct 2026 research, verify before procurement)
- **Local browser:** SD-Turbo (ONNX/WebGPU, ~512px, 1–4 steps; Stability Community licence, revenue threshold) for drafts; LaMa 208MB ONNX (Apache-2.0, fill-only, NOT prompt-semantic) + Real-ESRGAN ~67MB (BSD, upscale) for private cleanup; Moebius 1.27GB (Apache-2.0 port, mask-fill, no prompt). SD1.5-inpaint (OpenRAIL-M) heavier, prompt-capable but needs optimized export + 8GB+/WebGPU. SDXL 6.9GB / FLUX-12B ~24GB FP16: NOT browser defaults. Transformers.js does NOT support text-to-image — use dedicated ONNX pipeline.
- **Cloud:** OpenAI gpt-image-1 (~$0.011 low / $0.042 med / $0.167 high per 1024px, base64 return, no training by default, edit tokens extra, no verified cancel); Stability Core ~$0.03 / Ultra ~$0.08, inpaint $0.05 (users keep content but ToS permits improvement use unless opted out, no indemnity found); BFL FLUX Kontext Pro $0.04 / Max $0.08, Fill $0.05, async poll, 10-min URLs, API terms grant BFL perpetual licence to use inputs/outputs (review!); Replicate aggregator (Schnell $0.003, Dev $0.025, Pro $0.04, cancel+webhooks, 1h expiry, model-specific licences e.g. OpenRAIL vs Apache-2.0); fal.ai (FLUX 3 ~$0.024/MP, queue+cancel, configurable expiry, excludes training except Pending-Enterprise models). Adobe Firefly: commercial positioning + eligible indemnity but NO verified per-image price, OAuth server-to-server only, cache/task behaviour unverified — treat as contract-gated.
- **Stock:** Unsplash (free API 50/hr demo, 1000/hr prod; MUST trigger `download_location` on select, hotlink API URLs, photographer+UTM attribution; Plus content NOT assumed); Getty (RF vs rights-managed/editorial; API via account agreement); Shutterstock (free search/view, paid API sub for licence/download); Adobe Stock (Standard/Enhanced/Extended + Editorial-only with credit; API gated to Enterprise/approved). Pexels unverified (pages blocked) — do not certify.

## Architecture decision
Provider interface (`generateImage, editRegion, extendCanvas, createVariations, searchAssets, fetchLicensedAsset, upscale, capabilities, estimateCost, cancelTask`) with typed validation; providers implement subsets, UI shows availability/fallbacks (never simulate support). Lanes: (A) local cached models w/ hardware check + download consent; (B) opt-in remote generation; (C) permissioned search/download. Credentials server-side or secure BYOK only — never shipped secrets. Exact crop/preview + recipient/purpose/price shown before upload. Distinguish vendor retention from VoidCanvas local-file promise.

## Cost / abuse controls (release-blocking)
Per-operation estimate + confirm; per-user limits + global cap + quotas; rate-limit + auth on server endpoints; file validation + retention controls; provider outage/failed-billing policy; emergency off-switch (kill new tasks, drain running, keep editor functional, report `unconfigured`, never fake outputs).

## First beta floor
One working generation provider + one rights-aware search source + local upload/library fallback. Unavailable services must not interrupt editing (offline journey in 07). Re-verify pricing/licence/retention at procurement — this ADR is not a purchase order.
